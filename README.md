# The Pomodoro Technique 🍅 (and also my first React project)

The Pomodoro Technique is a time management method developed by Francesco Cirillo in the late 1980s. The technique consists of using a timer to divide work into 25-minute periods, separated by short breaks. -Wikipedia

In this project you will see how I use the Pomodoro Technique in a fully functional front-end page that stores your "pomodoros" as you use the timer!

https://chronos-pomodoro-black.vercel.app here is the page uploaded on vercel!
